# PlayStation web

PS5 系统风格的网页游戏库，8 款独立游戏，打开即玩。

- 线上地址：https://apple-pc.github.io/psweb/
- 开机动画 · 用户门 · 游戏库 · 奖杯 · 控制中心（Esc）· 启动转场
- 每款游戏是独立全屏页面，进入后不显示系统界面，仅 Esc 唤出控制中心
- 系统音效与游戏内音效全部由 Web Audio 实时合成，无外部音频文件（合并、消行、吃食物、翻牌、落子、开火、胜负均有对应音色）
- 会员：未激活时只能使用访客账户；在 [支持作者](https://apple-pc.github.io/psweb/afd/) 页或设定中输入密钥可解锁账户创建权
- 站点源码由 `generator/` 生成，`site/` 为构建产物；会员密钥用 `generator/gc_keys.py` 生成
