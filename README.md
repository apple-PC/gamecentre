# PlayStation web

PS5 系统风格的网页游戏库，8 款独立游戏，打开即玩。

- 线上地址：https://apple-pc.github.io/psweb/
- 开机动画 · 多用户 · 游戏库 · 奖杯 · 控制中心（Esc）· 启动转场
- 每款游戏有专属壁纸与独立页面，成绩与时长保存在本机
- 界面音效由 Web Audio 实时合成，无外部音频文件
- 站点源码由 `generator/` 生成，`site/` 为构建产物
